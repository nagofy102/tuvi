# Published chart candidate intake

Purpose: acquire a genuinely external chart oracle for milestone A, not enlarge
the source-counted synthetic corpus and relabel it independent publication.

## Required candidate record

| Field                  | Requirement                                                                                        |
| ---------------------- | -------------------------------------------------------------------------------------------------- |
| `id`, `status`         | Stable ID; candidate, blocked, admitted-partial or admitted-complete                               |
| `source`               | Title, author attribution, edition/date and institution/publisher; label uncertainty               |
| `locator`              | Actual accessible page/diagram identifier and lawful URL, not a search result alone                |
| `retrieval`            | Date, exact downloaded artifact digest, textual transcription and review record                    |
| `rights`               | Use/redistribution basis; no scans or copyrighted reports copied just because public               |
| `input`                | Original lunar/solar date, hour, gender and any expressly stated timezone/late-Tý/leap convention  |
| `expectedFields`       | Only legible published values; identify each field's diagram/page source                           |
| `unknownFields`        | Missing/illegible values and profile choices left open, not inferred from engine output            |
| `independence`         | Expected values sourced before comparison; no engine-generated, vendor snapshot or circular oracle |
| `profileCompatibility` | Explicit compatible convention, incompatible variant or unresolved; disagreements recorded         |
| `review`               | AI-assisted review separately labelled; no invented human approval or predictive validation        |

No actual candidate record is created by this template. Admission needs the
published evidence, not populated-looking placeholder inputs. A catalogue record
identifies a work but does not give a complete chart or prove the content's truth.

## Admission sequence

1. Retrieve the lawful source and identify the actual chart page. Redact unnecessary
   personal identifiers; prefer anonymous source examples. Never upload users'
   birth data to external services to create this evidence.
2. Transcribe visible input and fields without opening current engine output.
   Preserve uncertainty; do not guess missing time, Cục, star names or lunar date.
3. Record independently reviewed provenance, usage rights and profile compatibility.
   Count all reviewed cases separately from accepted complete/partial cases.
4. Admit only fields supported by source and compatible with the declared profile;
   unresolved/incompatible candidates stay blocked, not algorithm failures.
5. Compare with the engine after expected data are fixed under version control.
   Root-cause disagreements rather than replace expected values with actual ones.

## Complete versus partial

Complete admission requires the agreed chart-field coverage (not only Mệnh/Thân
and four auxiliaries), declared conventions and legible published placements.
The current 36 synthetic source-counted cases remain useful **partial** evidence
and must not be counted as 36 independently published complete charts. Dignity,
Tứ Hóa, vận and interpretation accuracy require their own scoped validation.

## No automatic promotion

Identified catalogue, matching book title, confirmed downloaded bytes and a
passing software test are distinct facts. None on its own authorizes a new star
group or opens D1/D2/D3. Milestone PM status remains in
[pm-milestone-status.md](../design/pm-milestone-status.md).
