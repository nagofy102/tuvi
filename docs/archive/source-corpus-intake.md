## Admission gate

`scripts/reference-diff.ts` rejects unsupported profile/status, duplicate source,
passage/case IDs, invalid branch labels, unadmitted expected stars and malformed
source/provenance references before any engine call. The runner only compares
accepted known fields. These checks enforce the current partial-corpus contract;
they cannot prove a supplied quotation or declaration of independence is truthful.
New expected star fields require an explicit reviewed contract change, not merely
adding names to the JSON. The v1 document format remains pinned-revision based;
facsimile-only intake needs a separately designed content-digest/page contract.
Expected field groups must reference their matching source passages, with no
unused provenance sources. Solar input, leap months and late Tý are outside this
v1 oracle scope and rejected; that restriction is not an application regression.
The literal Cục/Tử Vi example is scoped to the original documented input rather
than silently treated as a general formula. Mutation tests retain meaningful
assertions and check admission happens before any engine call.
